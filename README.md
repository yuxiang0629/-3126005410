🎮 按键功能详解
空闲状态（无自动任务运行时）
此时机械臂处于待命状态，可以响应按键和串口指令。

按键组合	对应指令	功能说明	使用场景
绿 1 (单独按 A)	G	循环夹取 A→B→C	演示自动夹取流程，每次按切换下一个物体
蓝 (单独按 B)	R	开始/停止录制动作	录制一套自定义动作序列
绿 2 (单独按 C)	P	播放已录制的动作序列	回放刚才录制的动作
红 (单独按 D)	M	机械臂回中位	紧急复位或准备新任务
绿 1 + 蓝 (同时按 A+B)	TCH	记录当前笔尖位置为示教点	用于后续画折线/曲线，最多 6 个点
绿 1 + 绿 2 (同时按 A+C)	DL	画直线	长度 120mm，起点 X=110mm, Y=105mm
绿 1 + 红 (同时按 A+D)	N / TRI	画三角形	中心 X=150mm, Y=105mm, 半径 50mm
蓝 + 绿 2 (同时按 B+C)	PLN	用示教点画折线	需先通过 TCH 记录≥2 个示教点
蓝 + 红 (同时按 B+D)	SMT	用示教点画平滑曲线	Catmull-Rom 样条插值，更圆润
绿 2 + 红 (同时按 C+D)	TRI	画三角形	与绿 1+ 红功能相同


💡 操作提示：组合键需要同时按住两个按键约 50ms 才能触发，避免误触。

自动运行中（任务二夹取、任务三播放、任务五绘图）
此时机械臂正在执行自动任务，部分按键功能会切换为过程控制。

按键	功能	详细说明
绿 1	暂停 / 继续	第一次按暂停当前动作，再按一次继续执行
蓝	继续	强制继续执行（仅在暂停状态下有效）
绿 2	继续	同上，备用按键
红	取消	立即中止当前动作并回中位（任何状态下都有效）


⚠️ 注意：自动运行中只有红色键能取消任务，其他按键（除暂停/继续外）无效。

标定步骤（首次使用必须做）
第 1 步：调手臂姿态
用摇杆把左臂、右臂调到"舒展前伸"姿态：

左臂约 2~10°（向前伸）
右臂约 118~168°（配合左臂高度）
爪子高度与物体齐平（不要太高或太低）
第 2 步：开实时打印
串口监视器发送 GB，返回以下表示已进入实时打印模式：

📝
Write
CMD> GB
CAL BASE ON
第 3 步：标夹取点
只用摇杆转底座（不要动左臂/右臂）
对准物体 A 的夹取方位
串口会不断打印 BASE=xx，抄下稳定时的值（如 BASE=46）
同样方法标出物体 B、C 的夹取点
示例输出：

📝
Write
BASE=46
BASE=47
BASE=46  ← 抄这个稳定值
第 4 步：标放置点
把物体分别放到目标位置
用同样方法标出 3 个放置点的底座角
通常放置点在另一侧，角度会更大（如 130°）
第 5 步：填参数
打开代码，找到 poses2[3][4] 数组，填入你抄到的 6 个角度：

cpp
const uint8_t poses2[3][4] = {
  // {L 左臂，R 右臂，夹取底座角，放置底座角}
  {  2, 118,  46, 130},  // 物体 A ← 改第 3、4 个数
  {  8, 168,  16, 145},  // 物体 B
  {  4, 150, 120,  20},  // 物体 C
};
💡 提示：第 1、2 个数（左臂/右臂角度）一般不用改，除非你调整了手臂姿态。

第 6 步：关打印
串口发送 GB，返回以下表示已关闭：

📝
Write
CMD> GB
CAL BASE OFF
调整抬起高度
如果夹取时撞到物体，可以调大抬起量：

cpp
const int LIFT_AMT = 15;   // 默认 15，可改为 20 或 25
⚠️ 重要：若实测抬臂方向相反（往下压而不是往上抬），把 updatePickMachine() 函数里 case 3 和 case 5 的 + LIFT_AMT 改成 - LIFT_AMT。

贴纸检测警告
如果某个示教点太靠近底座（手臂竖直导致笔尖抬高），生成路径时串口会打印：

📝
Write
WARN LOW-REACH X=85.50 Y=72.30 penZ=12.80
含义：

该点坐标：X=85.50mm, Y=72.30mm
笔尖实际高度：12.80mm
设定落笔高度：5.0mm
高出：7.80mm（可能画不到纸）
解决方法：

用摇杆把这个点往外（远离底座方向）挪一点
重新发 TCH 记录
再发 PLN 或 SMT 绘图
💡 经验值：安全区域为 X≥100mm 且 Y≥90mm，尽量不要超出这个范围。

❓ 常见问题
Q1: 夹取时爪子够不到物体怎么办？
A: 重新标定 poses2 里的左臂、右臂角度：

用摇杆调左臂/右臂到"舒展前伸"姿态
爪子高度与物体齐平
发 GB 开实时打印，抄下底座角度
填入 poses2 数组
Q2: 画圆/曲线时笔尖飘起来画不到纸？
A: 这是手臂太靠近底座导致的。解决方法：

把示教点整体往外移（增大 X/Y 值）
避开底座附近区域（X<100mm 或 Y<90mm）
串口警告 WARN LOW-REACH 就是在提醒你
Q3: 录制播放时动作不完整？
A: 检查是否录满了 40 帧：

📝
Write
CMD> R
REC 40
REC FULL  ← 录满了
如果动作太长，可以：

分段录制（分成多段）
加快操作速度（减少录制时间）
Q4: 抬臂时反而往下压？
A: 修改代码中的抬臂方向：

cpp
// updatePickMachine() 函数内
case 3:  // 抬臂
  setTarget(curB, poses2[stObj][0] - LIFT_AMT, curR, GRIP_CLOSE);  // 改 + 为 -
  ...
case 5:  // 落臂
  setTarget(curB, poses2[stObj][0], curR, GRIP_CLOSE);  // 保持不变
  ...
两处要一起改，才能抬得起、落得回。

Q5: 按键没反应？
A: 检查以下几点：

接线是否为内部上拉（D10~D13）
确认按下后为 LOW 电平（用万用表测）
如果按键常亮或常灭，可能是接线反了
检查消抖时间是否足够（代码中为 30ms）
Q6: 舵机抖动严重？
A: 可能是电源问题：

确认所有舵机共用 GND
使用外部 5V 电源供电（不要用 USB 供电）
检查电源电流是否足够（建议 2A 以上）
