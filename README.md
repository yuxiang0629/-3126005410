📖 项目简介
本项目为教学 / 竞赛用桌面机械臂综合控制系统，基于 Arduino UNO，采用 4 路舵机（底座 / 左臂 / 右臂 / 爪子）+ 双摇杆 + 4 键自制按键，将任务一 ~ 任务五的全部功能合并为单一 .ino 文件：

任务	名称	说明
任务一	手动操控	串口角度指令、双摇杆操控、爪开合、速度调节、回中
任务二	自动夹取放置	A/B/C 物体自动夹取 → 抬起 → 平移 → 落下 → 放置
任务三	录制 / 播放	录制并回放动作序列、循环夹取、回中（4 键）
任务四	正向运动学	打印各关节角度 + 末端世界坐标（正解验证）
任务五	绘图	末端铅笔绘制直线 / 三角形 / 示教折线 / 平滑曲线，可暂停 / 继续 / 取消


🎉 本版亮点
任务五绘图"第一点碰纸、后面几点悬空、没画完就飘走"​ —— 通过记录示教点真实压纸高度 + 绘图期间屏蔽摇杆解决。
任务二夹爪"一次夹不到底、夹的时候卡卡的"​ —— 通过"爪子优先 + 手臂逐关节逼近 + 夹紧稳位"优化舵机时序，降低电流峰值。
✨ 功能详解
任务一：手动操控
串口复合指令：x45 y45 z45 g30（空格分隔，一次设定 底座 / 左臂 / 右臂 / 爪子 角度）。
单轴指令：x45 / y45 / z45 / g30 分别单独设定某一轴。
爪：O 张开、S 闭合。
回中：M。
速度：H 加快、L 放慢（调节统一节拍 stepDelay，范围 2–40ms）。
双摇杆操控：左摇杆 X=底座、左摇杆 Y=左臂、右摇杆 X=爪子、右摇杆 Y=右臂；采用锁存式读取，兼容开关量输出的摇杆板。
非阻塞架构：串口、按键、摇杆 / 状态机 / 播放 / 绘图统一由 stepTick() 节拍驱动，互不卡顿。
任务二：自动夹取放置（底座主导 + 抬起 / 落下）
三组物体姿态表 poses2[3][4]，每组为 {左臂, 右臂, 夹取底座角, 放置底座角}。
完整流程（状态量 st）：
底座到夹取点（爪张开）
合爪夹稳（到位后稳位 400ms 才抬臂）
抬臂（左臂 +LIFT_AMT，底座不动）
底座平移到放置点（左臂保持抬起）
左臂落回（底座不动）
张开爪子放置（稳位 400ms）→ 完成
设计要点：底座主导水平位移，左臂仅在"抬起 / 落下"两段各动一次；夹取与放置时手臂基本不动。
触发：串口 G（按序 A→B→C）、A / B / C（指定物体）。
任务三：录制 / 播放
R 录制当前姿态（最多 MAX_REC = 40 点）。
P 播放录制序列。
空闲态 4 键：绿 1=G、蓝=R、绿 2=P、红=M。
任务四：正向运动学验证
T 打印：4 路舵机当前角度 + 肩 / 肘 / 笔尖的世界坐标 (X, Y, Z)​。
用于核对运动学正解、标定验证。
任务五：绘图（含贴纸检测）
直线 DL、三角形 N / TRI、示教折线 PLN、平滑曲线 SMT。
示教点 TCH：记录当前笔尖位置（本版新增 Z 高度记录）。
逆解 ikTo()：给定笔尖世界坐标 (X, Y, Z)，笔尖竖直朝下，求底座 / 左臂 / 右臂角度。
正解 calcPenZ()​：由舵机角反算笔尖实际高度，用于贴纸检测。
贴纸检测：落笔点超出工作空间时，串口打印 WARN LOW-REACH X=.. Y=.. penZ=.. 警告。
可暂停 / 继续 / 取消：绘图过程中绿 1=暂停 / 继续，蓝 / 绿 2=继续，红=取消。

🆕 v6.3 新增与改进
🖊️ 任务五：绘图接触优化
示教点新增 Z 高度记录：teachPoint() 同时记录 X / Y 和实际压纸高度 Z（tchZ[]），不再统一套用固定 PEN_Z，从根本上解决"第一点碰纸、后面几点悬空"。
折线 / 平滑曲线按示教高度还原：buildPolyline() 与 buildSpline() 沿线段对 Z 做线性过渡（tchZ[i] → tchZ[i+1]），笔尖全程贴合纸面。
绘图期间屏蔽摇杆：stepTick() 在绘图状态下不读摇杆，避免摇杆漂移 / 误触触发 abortAuto() 导致"没画完就飘走"；按键暂停 / 继续 / 取消仍可用。
保留 v6.1 的贴纸检测。
🤖 任务二：夹取 / 放置稳定性
删除冗余状态机：移除临时加入的 runTask2() 及其重复常量（GRAB_X / DROP_Y / LIFT_OFFSET / MOVE_MS / HOLD_MS 等），统一由 updatePickMachine()（状态量 st）驱动。
stepMove() 爪子优先、逐关节逼近：合爪 / 张爪时只有 1 个舵机在动，手臂三关节每拍只推进一个，避免 4 舵机同时启动造成电流峰值。
夹紧 / 放开稳位 150ms → 400ms。

⚠️ 已知限制与硬件建议
供电：UNO 的 5V 直驱 4 个舵机电流不足时会引发抖动、丢步。建议舵机独立供电并共地——软件层面无法根治。
舵机精度 / 回差：ikTo() 将角度取整带来 ±1° 量化误差，叠加舵机回差，笔尖高度偏差约 2–3mm 属正常。
夹爪方向与角度：若 GRIP_CLOSE = 140 仍夹不紧，可提高到 160；若角度增大时爪子反而张开，说明开合方向相反，请对调 GRIP_OPEN / GRIP_CLOSE。
工作空间：示教点若超出可达范围，串口打印 WARN LOW-REACH，请换更靠中间的坐标重新示教。
UNO 内存：绘图 / 录制数组已用 uint8_t 压缩，注意不要随意增大 MAX_PATH / MAX_REC。
