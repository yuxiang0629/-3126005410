# ARM 机械臂控制项目

基于 Arduino Uno 与 meArm 四舵机机械臂的完整控制系统，覆盖考核任务一至任务五：串口/摇杆操控、A/B/C 自动夹取、录制播放、运动学正逆解、轨迹绘制与过程控制。

## 版本亮点（v2.0.0）

- **非阻塞状态机**：夹取 / 播放 / 绘图均可被摇杆或任意指令随时打断
- **双输入通道**：电脑串口与按键板共用同一套指令解析，按键与手动输入完全等价
- **ESP8266 替代方案**：ESP8266 损坏后改用第二块 Arduino + 软串口按键板实现任务三
- **运动学正逆解**：`fk()` / `ik()` 落地任务四公式，`T` 指令实时打印末端 XYZ
- **轨迹绘制**：直线、图形、五点示教折线、Catmull-Rom 样条平滑，支持暂停/继续/取消
- **全量代码注释**：每个函数与关键逻辑均已标注说明

## 硬件方案

| 部件 | 说明 |
|---|---|
| 主控板 A | Arduino Uno，控制 4 个舵机 + 摇杆 + 串口监视器 |
| 按键板 B | 第二块 Arduino，D10\~D13 接 4 键（外部下拉电阻），替代 ESP8266 |
| meArm 机械臂 | 底座 / 肩 / 肘 / 爪 4 个舵机 |
| 双摇杆板 | 手动操控，右 X 控制爪子开合 |

## 板间通信（软串口）

| 按键板 B | 主控板 A | 说明 |
|---|---|---|
| D3（TX） | D2（RX） | 按键指令发送，必须接 |
| GND | GND | 必须共地 |
| D2（RX） | D3（TX） | 可选，主控回传 |

两板波特率均为 9600。

## 指令表

| 指令 | 功能 | 任务 |
|---|---|---|
| `x45` / `y45` / `z45` / `b45` | 肩/肘/腕/底座单关节到位 | 一 |
| `b90 x45 y45 z45` | 四关节同时到位 | 一 |
| `0` / `S` | 爪张开 / 闭合 | 一 |
| `H` / `L` | 提速 / 降速 | 一 |
| `M` | 回中（同时终止绘图/播放） | 一/三 |
| `A` / `B` / `C` | 夹取对应物体并放置 | 二 |
| `G` | 循环夹取 | 三 |
| `REC` / `PLY` | 录制 / 播放 | 三 |
| `T` | 打印末端 XYZ | 四 |
| `DL` / `N` / `TRI` / `Z` / `V` | 画直线 / 各图形 | 五 |
| `TCH` / `PLN` / `SMT` | 示教点 / 五点折线 / 五点平滑 | 五 |
| `PAUSE` / `RESUME` / `CANCEL` | 绘图暂停 / 继续 / 取消 | 五 |

## 文件说明

- `ARM.ino`：主控板 A 完整代码（任务一~五）
- `keypad.ino`：按键板 B 代码（4 键：G/REC/PLY/M）
- `说明文档.docx`：各任务实现逻辑详解

## 烧录前标定

1. **舵机偏移**：机械臂摆至"正前方、大臂水平、小臂伸直"基准姿态，填 `OFF_BASE / OFF_SHOULDER / OFF_ELBOW`；方向反了改映射符号
2. **绘图高度**：笔尖压纸后发 `T` 读 Z 值填 `PEN_Z`，或示教第一个点自动记录
3. **夹取点位**：用单关节指令实测 A/B/C 物体与放置点角度，填 `poses` 数组
4. **运动学参数**：`L1 / L2 / L3 / BASE_H` 按实物测量填写
