# ARM 机械臂控制项目

基于 Arduino 的 meArm 机械臂控制系统，当前完成：串口/摇杆双模式控制、A/B/C 物体夹取与放置。

## 硬件
- Arduino Uno + ArmJoystick U3.0 摇杆板
- meArm 机械臂（4个舵机）

## 串口指令
| 指令 | 功能 |
|---|---|
| `x45 y45 z45` | 三个关节同时移动到45度 |
| `x90` / `y90` / `z90` | 单个关节移动到指定角度 |
| `O` / `S` | 爪子张开 / 闭合 |
| `H` / `L` | 提速 / 降速 |
| `G` | 循环夹取（A→B→C切换） |
| `A` / `B` / `C` | 直接夹取对应物体 |
| `R` / `P` | 录制动作 / 播放 |
| `M` | 机械臂回中 |
| `T` | 打印当前关节角度和XYZ坐标 |
PS:当前的动作可随时打断执行下一个指令或使用摇杆
## 已完成功能
- **任务一**：串口指令 + 双摇杆双模式控制（左摇杆=底座/左臂，右摇杆=爪子/右臂）
- **任务二**：A/B/C 三个物体的夹取与放置（角度可标定，夹取过程可被打断）
