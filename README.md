二、本次发布重点（运动学模型修正）

v7.0 的核心工作是对机械臂运动学模型做了一次系统性修正。前期联调中，任务五绘图出现“笔尖偏高、够不到纸、串口频繁报 WARN LOW-REACH”的现象，经复核确认根因在于旧代码把 meArm 的“平行连杆”机构误当成了“串联相对角”模型。本次发布据此重建运动学，共四点修正：

① 机构模型改正为“平行连杆绝对角模型”

meArm 的底座之上是一组平行连杆：大臂、小臂各自由一只舵机独立决定其“绝对角度”，两杆互相独立。旧代码用 th2 = 90 − curR 把小臂当成“相对大臂的夹角”，属于模型性错误。v7.0 中，大臂绝对角 θ₁ 与小臂绝对角 θ₂ 分别直接由左臂、右臂舵机读数线性换算：

θ1 = SH_DIR  * (l − SH_CAL) * π/180    // 大臂绝对角（肩舵机）

θ2 = ELB_DIR * (r − ELB_CAL) * π/180   // 小臂绝对角（肘舵机）

② 水平/竖直常量分离，笔尖 = 肩轴正解 + 固定笔偏移 + 肩轴高度

不再把 L3 硬塞进角度里。笔尖相对腕轴的偏移 (PEN_DX, PEN_DZ) 由平行连杆保证恒定，因此在正解中作为常量叠加，结构参数与角度解耦：

wx = L1*cos(θ1) + L2*cos(θ2)          // 腕轴水平（相对肩轴）

wz = L1*sin(θ1) + L2*sin(θ2)          // 腕轴高度（相对肩轴）

rad = wx + PEN_DX                     // 笔尖水平（相对肩轴）

yaw = (b − BASE_CAL)*π/180            // 底座转角

px = rad*cos(yaw);  py = rad*sin(yaw)

pz = BASE_H + wz + PEN_DZ

③ 硬件相关量全部提为“可标定常量”

把结构尺寸、笔偏移、舵机标定与方向全部提为文件顶部的常量，实测后填入即可，公式无需改动，便于适配不同批次硬件。

④ 可达性检查：明确报错，不再“静默钳制”

画图前逐点判断是否超出臂展；超范围的点明确打印“OUT OF REACH ...”并跳过，不再静默把角度钳制到边界——后者会造成“笔尖莫名抬高、图形画歪”的隐蔽问题。

八、已知问题（遗留）

十、编译、烧录与使用

开发环境：Arduino IDE，板卡选择 Arduino UNO，端口选择对应串口。

依赖库：仅使用官方 Servo 库（#include <Servo.h>），无需第三方库。

烧录：打开 ARM_v7.0.ino，编译无误后上传。注意 UNO 仅 2KB RAM，务必保持数组为 uint8_t 以控制内存占用。

首次使用：按第四节表格实测并填入标定常量；用 PB / GB 读取底座角度、用 T 指令核对末端坐标。

验证：串口发送 T，比对打印的末端世界坐标与实测值；正逆解互验见运动学推导文档。
