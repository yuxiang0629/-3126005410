meArm 机械臂控制系统 · v2.0.0
> 舵机驱动的 4 自由度桌面机械臂控制系统（Arduino Uno）。
> 本版本完成考核任务一 ~ 任务五全部功能，并因 ESP8266 模块损坏，改用**第二块 Arduino 作为按键控制板**，通过软串口实现双板通信。
>
> 发布日期：2026-10-12
---
✨ 本版本亮点（Highlights）
🧠 非阻塞状态机架构：夹取 / 播放 / 绘图过程中，任意新指令或摇杆输入都能随时打断，无需等待当前动作结束。
🎮 双输入通道：电脑串口 + 按键板软串口，共用同一套指令分发逻辑，指令完全等价。
🔁 ESP8266 替代方案：原无线按键方案因模块损坏废弃，改为两块 Arduino 直连串口，指令链路与交互体验保持一致。
📐 运动学正解 / 逆解：内置 FK/IK，支持按末端 XYZ 坐标精确控制笔尖。
✏️ 轨迹绘制完整实现：直线、图形（N/三角形/Z/V）、五点示教折线、Catmull-Rom 样条平滑，支持暂停 / 继续 / 取消。
📝 全量代码注释：函数头说明、关键逻辑、标定参数均已标注，便于二次开发与答辩讲解。

🆕 新增与改动（What's Changed）
任务一 · 基础操控
单关节指令：`b` 底座、`x` 肩、`y` 肘、`z` 爪子
复合指令：`b90 x45 y45 z45`（四关节同时到位）
摇杆实时操控、爪子开合（`0` 张开 / `S` 闭合）、速度调节（`H` 提速 / `L` 降速）、回中（`M`）
摇杆映射（用户定制）：左 X=底座、左 Y=肩、右 Y=肘、右 X=爪子
任务二 · 自动夹取放置
`A` / `B` / `C` 触发对应物体的夹取—抬起—搬运—放置流程
`G` 循环抓取（A→B→C 自动切换）
全程非阻塞状态机，可被摇杆或新指令随时打断
任务三 · 录制 / 播放 / 按键控制
`REC`/`R` 录制当前位姿，`PLY`/`P` 回放（最多 60 组）
按键板通过软串口发送指令，与电脑串口走同一分发函数
按键方案：D10~D13 四按键，外部下拉电阻 + 上升沿触发（LOW→HIGH）
任务四 · 运动学
`T` 指令打印当前末端坐标 XYZ
正解 `fk()` / 逆解 `ik()`，含可达性判断
任务五 · 轨迹绘制
`DL` 直线、`N`/`TRI`/`Z`/`V` 图形
`TCH` 记录示教点（首个点自动记录绘图高度 `PEN_Z`）、`PLN` 五点折线、`SMT` 五点平滑
`PAUSE` / `RESUME` / `CANCEL` 过程控制
逐点逆解 + 插值，保证走线平直

🔧 硬件方案变更（Breaking Change）
原任务三方案使用 ESP8266 无线按键模块，因模块损坏无法烧录，本版本改为：
项目	旧方案	新方案（v2.0.0）
按键控制	ESP8266 无线	第二块 Arduino（按键板 B）
通信方式	WiFi / 无线	软串口 UART（9600）
接线	—	主控 D2(RX)←按键板 D3(TX)，两板共地
按键检测	内部上拉 + 下降沿	外部下拉 + 上升沿（D10~D13）
> ⚠️ 固件层面指令格式不变，上层交互逻辑无需修改。

⚙️ 使用前需标定（Calibration）
烧录前请按实物调整以下参数，其余逻辑无需改动：
`OFF_BASE` / `OFF_SHOULDER` / `OFF_ELBOW`：基准姿态舵机角
`L1` / `L2` / `L3` / `BASE_H`：机械臂连杆长度（mm）
`poses[][][]`：A/B/C 物体的夹取位与放置位角度
`PEN_Z`：笔尖绘图高度（可由首个示教点自动记录）

⚠️ 已知问题（Known Issues）
舵机角度偏移、连杆长度、夹取点位、绘图高度需按实物实测标定后才能获得理想精度。
样条平滑需 ≥2 个示教点，点位过少时退化为直线。
烧录时若提示端口忙，请先关闭串口监视器再上传。
